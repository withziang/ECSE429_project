# ECSE 429 Project

Testing the Thingifier REST API todo list manager (v1.5.5).

## Layout

- `src/` application under test: runnable jar and `run.sh`
- `test/` test suite

## Run

Requires Java 8+.

```
./src/run.sh
```

Serves on http://localhost:4567, docs at `/docs`. Stop with Ctrl+C or `GET /shutdown`.
